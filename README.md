# 📈 股票分析小幫手（v3 智慧波浪與多因子版）

輸入任何台股或美股代號，可以看到：

- **🏠 總覽**：🌦️ 大盤氣象站（0050／S&P 500）、每檔的「買進時機」建議、🌊 波浪階段、💪 相對大盤強弱（RS）、綜合評估與五面向雷達圖
- **📊 個股分析**：🤖 AI 分析師（白話解讀波浪位置、黃金分割百分比、🐂 多方 vs. 🐻 空方辯論、🎯 明日 If-Then 操作劇本）、🎯 **三週期買點雷達（有效K棒：短／中／長線）**、五個面向分數拆解、🧱 壓力支撐、🛡️ ATR 動態停損停利與單筆風險部位計算機、以及 K 線圖（含 ZigZag 波浪標示 `①②③④⑤／ⓐⓑⓒ`、黃金分割線、有效K棒與起漲確認標記、分價量表）
- **🌊 波浪與相似K線**：艾略特波浪理論轉折路徑、費波那契黃金分割回撤位（`23.6%／38.2%／50%／61.8%／78.6%`）與延伸目標價（`127.2%／161.8%`）、頂底背離偵測，以及 **🔍 歷史最相似 10 次 K 線走勢比對**（未來 60 日推演扇形圖與勝率）
- **🏦 籌碼**：三大法人買賣超、投信連買與 3 日轉折、融資餘額與 5 日斷頭清洗訊號（台股）
- **📑 基本面**：月營收與年增率、EPS、毛利率、本益比走勢（台股個股）
- **📰 消息**：近期新聞，AI 逐則判讀偏多或偏空
- **🧪 回測**：目前使用的模型與其他組合的歷史表現比較（含 ATR 動態停損停利出場模擬）
- **⚖️ 比較**：多檔股票的評分、波浪階段、RS 相對強弱、走勢、報酬、波動、最大回撤和相關性

## 兩個分數

| 分數 | 用途 |
|---|---|
| 🎯 買進時機 | 技術與波浪「長多黃金分割回檔、先超賣後止跌」+ 籌碼濾網，**決定買進建議**（經回測驗證） |
| 🏅 綜合評估 | 技術波浪、籌碼、基本面、估值、消息五面向加權，用來看公司體質與風險 |

詳細規則和回測研究結果在網頁的「📖 說明」分頁。

## 設定（選填）

`.streamlit/secrets.toml`（隱藏資料夾，在 Finder 按 ⌘ + Shift + . 顯示）：

```toml
GEMINI_API_KEY = "你的 Gemini 金鑰"   # 啟用 AI 分析師與新聞情緒判讀
GEMINI_MODEL = "gemini-3.6-flash"     # 免費層級推薦使用 gemini-3.6-flash
FINMIND_TOKEN = ""                    # 選填：FinMind 免費帳號 token，提高查詢次數上限
```

這個檔案只存在你的電腦，不要分享給別人。

## 啟動方式

**方法一（最簡單）**：在 Finder 裡雙擊 `啟動.command`，瀏覽器會自動打開。

> 第一次雙擊時，macOS 可能會擋下來。請改用「右鍵 → 打開」，再按「打開」。

**方法二**：在終端機執行

```bash
cd ~/Desktop/vino/stock-dashboard
~/.local/bin/uv run streamlit run app.py
```

然後打開 http://localhost:8501

## 怎麼輸入股票

| 類型 | 範例 |
|---|---|
| 台股上市 / 上櫃 | `2330`、`0050`、`00981A`（會自動判斷上市或上櫃） |
| 美股 | `NVDA`、`AAPL`、`SPY` |
| 中文名稱（常見的） | `台積電`、`國巨`、`輝達` |
| 指定交易所 | `2330.TW`、`6488.TWO` |

多檔用逗號或空白分隔。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `app.py` | Streamlit 網頁介面 |
| `waves.py` | 艾略特波浪理論（ZigZag 轉折標示）、費波那契黃金分割率、頂底背離、歷史前 10 次相似 K 線比對 |
| `keybar.py` | 有效K棒（放量長紅／長黑）、起漲確認（突破K高／回測1/2不破）、短中長三週期狀態與回測（第二套獨立訊號） |
| `model.py` | 技術與波浪指標、10 日超賣記憶評分、ATR 動態停損停利回測 |
| `factors.py` | 籌碼轉折、基本面、估值評分、壓力支撐與 ATR 風控、綜合評估 |
| `analysis.py` | 整合所有面向、大盤氣象站與相對強弱 RS、買進建議規則、AI Context |
| `sources.py` | FinMind（台股籌碼、營收、財報、本益比、新聞）與美股基本面（含 `data_cache/` 本機快取） |
| `ai.py` | Gemini：新聞情緒、AI 分析師（波浪解讀、多空辯論、If-Then 劇本） |
| `data.py` | 抓取股價、台股最新日 K 自動補齊、代號解析、中文名稱對照 |
| `啟動.command` | 雙擊啟動 |

## ⚠️ 注意

- 股價來自 Yahoo Finance（若台股 Yahoo 落後一天，會自動從 FinMind 補上最新收盤日 K），台股籌碼 / 財報 / 新聞來自 FinMind 免費 API（搭配 `data_cache/` 本機快取節省額度）。
- 券商分點（主力）資料需要 FinMind 付費方案，目前用三大法人 + 融資代替。
- **僅供學習參考，不構成投資建議**。
